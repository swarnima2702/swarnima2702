## 🚀 Featured Project

### 🌉 SkillBridge — From Skills to Job-Ready

> A full-stack MERN platform that verifies what you know and builds your resume from proof, not claims.

- **Skill Path** → enter your skills → matched roles → assessments → gap-filling learning plan → resume
- **Job Path** → pick a target role → personalised learning plan → assessments → **AI mock interview** → resume
- **Verified resume** → assessments, progress tracking and the AI interview feed an auto-generated, achievement-based resume
- **Earn while you grow** → job-ready users can take on paid freelance tasks
- **My role:** Frontend development with React
